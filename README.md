# Primer entregable — Sistema de Gestión Académica en Java

## Objetivo

Desarrollar una aplicación de consola en Java que permita administrar estudiantes, profesores, materias y calificaciones utilizando programación orientada a objetos.

El proyecto tiene como finalidad aplicar los conocimientos aprendidos durante las primeras unidades del curso, incluyendo:

- Clases y objetos
- Métodos y constructores
- Decisiones y bucles
- Herencia
- Encapsulamiento
- Polimorfismo
- Arrays o ArrayList
- Manejo de cadenas y fechas

---

# Descripción del Proyecto

Una institución académica necesita un sistema para administrar la información de sus estudiantes y materias.

El sistema deberá permitir registrar estudiantes, profesores y materias; asignar materias a estudiantes; registrar calificaciones; realizar búsquedas; y mostrar reportes básicos académicos.

La aplicación deberá funcionar completamente desde consola mediante un menú interactivo.

---

# Menú del Sistema

```text
====================================
   SISTEMA DE GESTIÓN ACADÉMICA
====================================

1. Registrar estudiante
2. Registrar profesor
3. Registrar materia
4. Asignar materia a estudiante
5. Registrar calificación
6. Buscar estudiante
7. Mostrar estudiantes
8. Mostrar materias
9. Mostrar reporte de promedios
10. Salir
```

---

# Requisitos Funcionales

## 1. Registrar estudiante

El sistema debe permitir registrar estudiantes con información como:

- Matrícula
- Nombre
- Apellido
- Edad
- Carrera
- Fecha de inscripción

---

## 2. Registrar profesor

El sistema debe permitir registrar profesores con información como:

- Código
- Nombre
- Apellido
- Especialidad

---

## 3. Registrar materia

El sistema debe permitir registrar materias con información como:

- Código
- Nombre de la materia
- Cantidad de créditos

---

## 4. Asignar materia a estudiante

El sistema debe permitir asignar una o varias materias a un estudiante registrado.

---

## 5. Registrar calificación

El sistema debe permitir registrar calificaciones a los estudiantes por materia.

---

## 6. Buscar estudiante

El sistema debe permitir buscar estudiantes por:

- Matrícula
- Nombre

---

## 7. Mostrar estudiantes

Mostrar todos los estudiantes registrados en el sistema.

---

## 8. Mostrar materias

Mostrar todas las materias registradas en el sistema.

---

## 9. Mostrar reporte de promedios

Mostrar el promedio general de cada estudiante y determinar si:

- Aprobó
- Reprobó

- No se permite desarrollar toda la lógica dentro del método `main`.
- El proyecto debe estar organizado en múltiples clases.
- Debe existir separación lógica entre entidades del sistema.
- El sistema debe validar entradas inválidas siempre que sea posible.
